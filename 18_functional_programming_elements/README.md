## Тема: Элементы функционального программирования

### Задача 1. Сортировка прайса

**Дано:** Дан список словарей, описывающих товары в интернет-магазине автозапчастей. Каждый словарь содержит название детали и её стоимость.

Используя функцию `sorted()` вместе с анонимной функцией `lambda`, отсортируй список товаров по их стоимости **от самых дорогих к самым дешевым** (по убыванию). Выведи отсортированный список в консоль.

**Решение:**

```python
catalog = [
    {"item": "Brake Pads", "price": 4500},
    {"item": "Oil Filter", "price": 1200},
    {"item": "Spark Plugs", "price": 2500},
    {"item": "Windshield Wipers", "price": 1800},
]

result = sorted(catalog, key=lambda item: item["price"], reverse=True)

for product in result:
    print(product)
```

### Задача 2. Чистка логов

**Дано:** В системе тестирования API логгер сохранил список строк-ответов от сервера, но все они записаны в разном регистре (то строчные, то заглавные буквы).

Используя функцию `map()` совместно с `lambda`, приведи каждую строку в списке к нижнему регистру и сделай так, чтобы первая буква стала заглавной (метод `.capitalize()`). Преврати результат обратно в список и выведи его.

**Решение:**

```python
responses = ["status: OK", "ERROR 504", "not found", "BAD gateway"]

answer = list(map(lambda resp: resp.lower().capitalize(), responses))
print(answer)
```

### Задача 3. Фильтрация лагов

**Дано:** В процессе автоматизированного тестирования производительности бэкенда был зафиксирован список времени отклика сервиса (в миллисекундах) за различные интервалы времени.
Используя функцию `filter()` и `lambda`, отфильтруй этот список так, чтобы в нем остались **только «медленные» запросы**, время отклика которых превышает или равно пороговому значению в 200 мс. Выведи отфильтрованный список.

**Решение:**

```python
response_times = [45, 120, 210, 85, 300, 199, 450, 95]

response = list(filter(lambda time: time >= 200, response_times))
print(response)
```
