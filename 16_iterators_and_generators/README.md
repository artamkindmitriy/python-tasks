## **Тема: Итераторы и Генераторы**

### **Задача 1. Кастомный итератор по логам**

**Дано:** Реализуйте пользовательский класс-итератор `LogIterator`, предназначенный для фильтрации лог-файлов в рамках автоматизации тестирования. Класс должен принимать на вход список строк-логов и возвращать при обходе исключительно те элементы, которые содержат ключевое слово `"ERROR"`.

- В классе должны быть явно реализованы магические методы `__iter__()` и `__next__()`.
- При исчерпании элементов, содержащих ошибку, итератор должен корректно завершать работу путем генерации исключения `StopIteration`.

**Решение:**

```python
class LogIterator:
    def __init__(self, logs: list[str]):
        self.logs = logs
        self.index = 0

    def __iter__(self):
        return self

    def __next__(self):
        while self.index < len(self.logs):
            log = self.logs[self.index]
            self.index += 1

            if "ERROR" in log:
                return log

        raise StopIteration
```

### Задача 2. Генератор тестовых данных

**Дано:** Реализуйте функцию-генератор `generate_test_users(count: int)`, предназначенную для динамического формирования наборов тестовых данных без предварительного выделения памяти под всю последовательность.

- Функция должна принимать аргумент `count`, определяющий общее количество генерируемых сущностей.
- С использованием ключевого слова `yield` функция должна поочередно возвращать словари со структурой тестовых данных: `{"id": <порядковый_номер>, "email": "user_<номер>@test.com", ...}` вплоть до достижения лимита `count`.

**Решение:**

```python
def generate_test_users(count: int):
    for i in range(1, count + 1):
        yield {
            "id": i,
            "email": f"user_{i}@test.com"
        }

gen = generate_test_users(5)

for user in gen:
    print(user)
```
